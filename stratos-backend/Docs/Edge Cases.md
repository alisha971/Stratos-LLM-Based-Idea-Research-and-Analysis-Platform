# Edge Cases

# The Ones that are covered in the flowcharts

✔ User cannot clarify idea → AI proposes hypotheses

✔ Search API down → LLM fallback mode

✔ Webpage blocked/JS-heavy → snippet-only mode

✔ No competitors found → explain whitespace opportunity

✔ No relevant papers → fallback to broader theoretical discussion

✔ Query returns no RAG chunks → fallback to LLM-only reasoning

✔ Contradicting user answers → ask to resolve conflict

✔ User denies market research → keep clarifying idea

✔ Toxic or illegal domains → safety filtering
